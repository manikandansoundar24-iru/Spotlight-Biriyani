# Spot Light Manager — Client Proposal

## 1. Proposal title
Spot Light Manager — Smart Billing, Stock, and Profit Management for Restaurants

## 2. Introduction
Spot Light Manager is a modern digital solution designed for restaurants, biriyani shops, and cloud kitchens to simplify day-to-day operations. It helps owners and staff manage billing, stock, profit tracking, and reporting from a single platform.

This solution is built to help businesses reduce manual errors, improve decision-making, and understand profitability more clearly.

## 3. The problem
Many restaurants still run their business using notebooks, WhatsApp messages, or separate tools for billing and stock. This creates several issues:
- poor visibility of daily sales
- difficulty tracking profit per order
- manual errors in billing
- limited stock control
- uncertainty about Swiggy and Zomato profitability
- lack of simple reports for owners

## 4. Our solution
Spot Light Manager brings essential operations into one simple dashboard.

It allows the business to:
- bill orders quickly
- track food cost and profit
- monitor stock levels
- view sales and report trends
- understand channel profitability
- manage branch-wise operations in a future-ready system

## 5. Key features
### Billing
- fast order entry
- counter and online channel support
- discount handling
- payment mode tracking
- profit visibility before saving the bill

### Stock management
- raw material tracking
- reorder alerts
- purchase and usage logs
- wastage tracking

### Reporting
- daily and monthly sales summaries
- profit analysis
- item-wise sales reports
- prepared forecast for upcoming demand

### Website and brand presence
- public website for customers
- menu display
- branch details
- contact and delivery information

## 6. Why this is valuable for the client
This system helps the owner save time, improve control, and make better business decisions.

Benefits include:
- less manual work
- faster billing
- better stock control
- clearer profit reporting
- better visibility into online platform performance
- stronger operational discipline

## 7. Ideal customers
This solution is ideal for:
- biriyani shops
- small restaurants
- cloud kitchens
- tiffin centers
- multi-branch food businesses that want better control

## 12. Current technology stack used in this project

### Frontend
- React 19
- TypeScript 5.8
- Vite 8
- TanStack Router / TanStack Start
- Tailwind CSS 4
- Recharts
- Radix UI components

### Runtime
- Node.js 24.x (portable runtime used locally in this environment)
- npm 11.x

### Data layer
- browser localStorage
- no production backend database in the current version

### Backend status
- no Java backend
- no Python backend
- no Spring Boot backend
- current version is frontend-first and local-storage based

This means the current product is modern and demo-ready, but it is not yet a full enterprise ERP backend system.
