# Spot Light Manager — One-Page Business Plan

## Business concept
Spot Light Manager is a restaurant management solution for biriyani shops, small restaurants, and cloud kitchens. It helps owners manage billing, stock, profit, and reporting from one simple platform.

## Problem
Most restaurants still depend on manual processes, notebooks, and fragmented tools. This causes billing delays, poor visibility into profit, weak stock control, and limited reporting.

## Solution
Spot Light Manager digitizes the core day-to-day operations of a food business. It offers a simple dashboard for billing, stock monitoring, profitability analysis, and reporting.

## Target customers
- biriyani shops
- small restaurants
- cloud kitchens
- tiffin centers
- growing food businesses

## Value proposition
The software helps owners save time, reduce mistakes, improve profit visibility, and run the business more professionally.

## Core features
- fast billing
- stock tracking
- profit and cost visibility
- sales reports
- branch-ready structure
- website and brand presence

## Revenue model
Possible business models:
- one-time setup + annual support
- monthly subscription
- hybrid setup with monthly recurring support

## Go-to-market approach
- target local restaurant owners directly
- show a live demo with real numbers
- offer onboarding and training
- upsell cloud features and advanced modules later

## Competitive advantage
The product is practical, easy to demonstrate, and designed specifically for restaurant operations. It is simple enough for a small shop owner to adopt quickly.

## Current tech stack
- Frontend: React 19
- Language: TypeScript 5.8
- Build tool: Vite 8
- Routing: TanStack Router / TanStack Start
- Styling: Tailwind CSS 4
- Data layer: browser localStorage
- Runtime: Node.js 24.x / npm 11.x

## Important note
The current version is modern and demo-ready, but it is still a frontend-first local product. It is not yet a full Java/Spring Boot enterprise backend system.
